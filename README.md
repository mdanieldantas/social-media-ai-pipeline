# social-media-ai-pipeline
# 🤖 Instagram AI Automation & Analytics Pipeline

Pipeline modular desenvolvido em **Node.js** e integrado com **Inteligência Artificial** para extração de dados públicos do Instagram, processamento de transcrições de vídeos e análise profunda de perfis de comunicação e engajamento.

---

## 📂 Estrutura do Projeto

O repositório está organizado para separar a documentação de arquitetura, os prompts de automação baseados em MCP (Model Context Protocol) e os recursos de mídia:

```text
projeto-instagram/
├── resources/
│   ├── docs/          # Diagramas de arquitetura e documentação geral (.excalidraw)
│   ├── prompts/       # Prompts e instruções estruturadas para automação (ex: MCPs)
│   └── videos/        # Arquivos de mídia e dados estruturados por conta (<conta>/lista.csv)
├── mcps/              # Implementações de Model Context Protocol (Node.js)
└── README.md
